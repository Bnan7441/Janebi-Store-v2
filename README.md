# 📱 فروشگاه آنلاین لوازم جانبی موبایل (Janebi Arena)

یک پروژه مدرن، سریع و کامل فروشگاهی برای عرضه لوازم جانبی موبایل و دیجیتال که با استفاده از جدیدترین تکنولوژی‌های وب ساخته شده است. این سیستم شامل پنل کامل محصولات، سبد خرید پیشرفته، حالت تاریک/روشن، قابلیت مقایسه، لیست علاقه‌مندی‌ها و پاسخگوی هوشمند مشتریان می‌باشد.

---

## 🚀 ویژگی‌های کلیدی (Features)

- 🎨 **طراحی مدرن و زیبایی‌شناسی (UI/UX)**:
  - پشتیبانی کامل و هوشمند از **حالت تاریک (Dark Mode)** و **حالت روشن (Light Mode)**.
  - تایپوگرافی فارسی استاندارد با فونت **وزیرمتن (Vazirmatn)** و چیدمان کاملاً راست‌چین (RTL).
  - انیمیشن‌های نرم و بی‌نقص با استفاده از `motion` (Framer Motion).

- 🛍️ **تجربه خرید و فروشگاهی (E-commerce Features)**:
  - **کاتالوگ هوشمند محصولات**: فیلتر بر اساس دسته‌بندی، برند، محدوده قیمت، موجودی و مرتب‌سازی‌های متنوع.
  - **سبد خرید تعاملی**: نوار هوشمند پیشرفت ارسال رایگان (سقف ۲,۰۰۰,۰۰۰ تومان)، محاسبه آنی فاکتور و ذخیره‌سازی محلی.
  - **فرآیند تسویه‌حساب (Checkout)**: فرم چند مرحله‌ای ورود اطلاعات گیرنده، انتخاب نحوه ارسال و پرداخت به همراه صدور فاکتور و شناسه پیگیری.
  - **مقایسه کالاها (Compare)**: جدولی برای مقایسه ویژگی‌ها، قیمت و گارانتی محصولات مختلف تا ۴ کالا.
  - **لیست علاقه‌مندی‌ها (Wishlist)**: امکان نشان‌کردن و ذخیره کالاهای مورد علاقه.
  - **تاریخچه سفارشات (Order History)**: مشاهده سفارش‌های ثبت شده قبلی با وضعیت پردازش و جزییات فاکتور.

- 🤖 **دستیار هوشمند جانبی آرنا (AI Chat Widget)**:
  - ویجت چت هوشمند برای راهنمایی خریداران و پاسخگویی به سوالات مربوط به شارژر، گلس و قاب.

## 🛠️ تکنولوژی‌های استفاده‌شده (Tech Stack)

### **فرانت‌اند (Frontend)**
- **فریک‌ورک**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **بندلر**: [Vite 8](https://vitejs.dev/)
- **استایل‌دهی**: [TailwindCSS v4](https://tailwindcss.com/)
- **مسیریابی**: [React Router v7](https://reactrouter.com/)
- **آیکون‌ها**: [Lucide React](https://lucide.dev/)
- **انیمیشن**: [Motion / Framer Motion](https://motion.dev/)

### **بک‌اند (Backend)**
- **سرور**: [Express 5](https://expressjs.com/) روی Node.js
- **کامپایل بک‌اند**: `esbuild` + `tsx`
- **معماری سرویس**: RESTful API جهت ارائه لیست و جزئیات محصولات و مدیریت حالت توسعه با Vite Middleware.

## ⚙️ راهنمای اجرا در محیط محلی (Local Setup)

### پیش‌نیازها
- **Node.js**: نسخه 18 یا بالاتر
- **npm**: نسخه 9 یا بالاتر

### مراحل نصب و اجرا

1. **نصب وابستگی‌ها**:
   ```bash
   npm install
   ```

2. **اجرای سرور توسعه (Development)**:
   ```bash
   npm run dev
   ```
   برنامه روی آدرس `http://localhost:3000` به همراه قابلیت Hot Module Replacement (HMR) اجرا می‌شود.

3. **تست تایپ‌اسکریپت (Type Check)**:
   ```bash
   npm run lint
   ```

4. **ساخت خروجی پروداکشن (Build)**:
   ```bash
   npm run build
   ```

5. **اجرای نسخه نهایی ساخت‌شده (Start Production)**:
   ```bash
   npm start
   ```
